## 🤖 自主代理 (Autonomous Agents)

### [OpenClaw](https://github.com/openclaw/openclaw)
- **描述**: 一个可在任何操作系统/平台上运行的个人 AI 助手，具备自我扩展技能能力，完全本地运行无需依赖云端
- **热度**: ⭐ 2026 年 GitHub 历史上增长最快的项目，近期星标爆发式增长
- **特点**: 被赞誉为 Agent 自主性的"龙虾之道"

### [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)
- **描述**: 使用自然语言指令进行任务解决的自主代理，对所有用户友好可访问
- **热度**: ⭐ 高星标和 fork 数；Agent 领域的奠基性项目
- **特点**: 经典高热度项目；在实际任务自动化方面评分最高

### [Qwen-Agent](https://github.com/QwenLM/Qwen-Agent)
- **描述**: 支持多提供商 LLM、工具和调度的 Agent 框架，用于自主任务
- **热度**: ⭐ 在 X 平台讨论中 trending；星标快速增长
- **特点**: 快速崛起的流行度；通用 Agent 的高评分

## 🌐 多智能体系统 (Multi-Agent Systems)

### [CrewAI](https://github.com/crewAIInc/crewAI)
- **描述**: 用于创建具有角色、任务和工具的多智能体"团队"框架，支持协作工作流程
- **热度**: ⭐ 2025-2026 年快速增长；高参与度
- **特点**: 商业自动化方面评分最高；在结构化 Agent 团队中表现出色

### [AutoGen](https://github.com/microsoft/autogen)
- **描述**: 微软出品的支持人机协作的多智能体框架，用于协作式 AI 应用
- **热度**: ⭐ 在基准测试中表现顶尖；强大的社区评分
- **特点**: 企业采用度高热度；被评为最适合可扩展 Agent 集群的框架

### [LangGraph](https://github.com/langchain-ai/langgraph)
- **描述**: 基于 LangChain 构建的有状态 Agent 框架，支持可控工作流程和流式传输
- **热度**: ⭐ 2026 年快速崛起；在 Agent 工具中高星标
- **特点**: 生产级 Agent 评分最高；基准测试中低延迟

### [OWL](https://github.com/camel-ai/owl)
- **描述**: 支持浏览器/终端访问和 MCP 工具的多智能体协作框架
- **热度**: ⭐ 开源 GAIA 基准测试榜首（58.18%）
- **特点**: 协作 Agent 高评分；在新项目列表中崛起

### [AgentForge](https://github.com/DataBassGit/AgentForge)
- **描述**: LLM 无关的平台，用于构建和测试多智能体系统
- **热度**: ⭐ 在目录中被推荐；强大的自定义 Agent 支持
- **特点**: 灵活性评估高；在用例集合中崛起

## ⚡ 工作流自动化 (Workflow Automation)

### [n8n](https://github.com/n8n-io/n8n)
- **描述**: 具有 AI 原生功能的工作流自动化平台，用于构建 Agent 管道、集成和自定义自动化
- **热度**: ⭐ 16万+ 星标，2025 年 Agentic AI 仓库榜首
- **特点**: 最高整体热度；在 Agent 工作流方面表现出色，支持 fair-code 许可证和 LLM 集成

### [Langflow](https://github.com/langflow-ai/langflow)
- **描述**: 用于设计 AI Agent 和 RAG 工作流程的低代码平台，支持拖放式 LLM 链
- **热度**: ⭐ 14万+ 星标，需求激增
- **特点**: 在构建 Agent 的易用性方面评分最高；在生产就绪应用中表现强劲的基准测试

## 🏗️ Agent 框架与平台

### [Ollama](https://github.com/ollama/ollama)
- **描述**: 用于本地运行 LLM 的轻量级框架，无需 API 即可支持 Agent 用例
- **热度**: ⭐ 2026 年大规模增长；高 fork 数和贡献者数
- **特点**: 开源可访问性方面热度最高；针对硬件优化 Agent 的评分

### [OpenFang](https://github.com/RightNow-AI/openfang)
- **描述**: 基于 Rust 的 Agent 操作系统，用于运行具有调度和多 LLM 支持的自主 Agent
- **热度**: ⭐ 早期项目但在 X 平台 trending；"Agent 的操作系统层"概念
- **特点**: 快速崛起的潜力；在抽象概念方面社区兴趣高

## ⚙️ 自动化说明

本项目采用 **Apify + GitHub Actions** 实现每日自动扫描：

### 🔧 技术栈
- **Apify**: 云端爬虫服务，抓取 GitHub Trending 和 X(Twitter) 数据
- **GitHub Actions**: 每天 UTC 8:00 (北京时间 16:00) 自动运行
- **评分算法**: 综合 GitHub 星标增长、X 平台提及数等多维度数据

## 📈 趋势分析

### 2025-2026 年关键趋势

| 趋势 | 说明 |
|------|------|
| **多智能体协作** | CrewAI、AutoGen、OWL 等框架推动多 Agent 协作成为主流 |
| **本地优先** | OpenClaw、Ollama 等项目强调本地运行，减少对云服务的依赖 |
| **工作流可视化** | Langflow、n8n 提供低代码/无代码方式构建复杂 Agent 工作流 |
| **Agent 操作系统** | OpenFang 等新兴项目开始探索 Agent 专用的操作系统层 |
| **推理优化** | DeepSeek-V3 等模型在推理能力和 Agent 任务上达到新高度 |

## 🤝 贡献指南

我们欢迎 contributions！请查看 [CONTRIBUTING.md](./CONTRIBUTING.md) 了解如何参与。

### 贡献方式

1. **提交新项目**: 发现符合标准的优秀 Agent 或 Skill 项目
2. **更新信息**: 帮助更新项目的星标数、描述或其他信息
3. **改进分类**: 建议更好的分类方式
4. **修复错误**: 报告或修复链接错误、描述错误等

### 提交标准

在提交新项目时，请确保项目符合以下至少一项标准：

- [ ] 星标增长迅速（过去 3 个月增长 50%+）
- [ ] 总星标数超过 10,000
- [ ] 在权威基准测试（如 GAIA）中表现优异
- [ ] 在社区中获得广泛好评和推荐
